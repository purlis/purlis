### Added

- **Use skill… has a key: `⌘⇧S`, or `Ctrl+Shift+S` off a Mac.** It opens Use skill… on the chat in front, and Shortcuts lists it (#3954).

### Changed

- **A chat's skills chip turns warning-coloured for every need of the chat's own that the Skills view lists:** its budget, pins it does not read, a router that fell back, skills it started without, or skills changed since it started. Its tooltip names each (#3953).
- **The Use skill… row no longer says the chat's budget.** The Skills view says it (#3954).
