### Changed

- **The Skill studio's Harness skills and Routing pages** (Skill studio preview, #3692). Harness
  skills lists each program's own skills under its name, each with whose it is (you, a repo, a
  plugin) and one mark; the skill chosen opens beside the list with its facts and an on/off
  switch for these chats, or says why a plugin's is read-only. A program with none says so.
  Routing says the router these chats are routed by, with Change… to pick the built-in router or
  an installed router extension for a workspace or a persona, the budget, and how the router did
  at each chat's start: its timing, or that it fell back, and what it hid.
