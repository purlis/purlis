### Added

- **Set a theme's options per project and workspace.** Settings › Theme lets you pick the value of
  each of the chosen theme's options at You, Project and Workspace, kept on your machine with
  your theme choice. The nearest level's values are drawn, and each value's badge names the
  level that chose it (#2527).

### Changed

- **A theme choice names the level of the folder it picked.** Choosing a theme folder in Settings
  › Theme now records whether it is your own, the project's or the workspace's, so a folder of
  the same name at another level is never drawn in its place. The gallery shows a card for each
  folder of one name, each saying its level. Choices made before keep drawing as they did and
  gain their level the next time they are written (#2516).
