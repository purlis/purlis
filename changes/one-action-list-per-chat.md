### Changed

- **A chat's actions are one list, the same on its pane, its sidebar row and in the palette.**
  The pane's new ⋯, the row's ⋯ (on hover and focus), its right-click and Shift+F10 all open the
  same list in the same words, and the palette has a row for each action of every chat,
  including chats with no tab. Rename, Restart, Start fresh, Move to, the work link, Use skill,
  Ask, Activity, Network and the new End… act on that chat, never on its tab's first pane. A
  tab's right-click holds only the tab's own rows. A row that can't run now is greyed with its
  reason, such as Start fresh while nothing the chat read has changed (#4753).
