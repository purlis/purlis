### Security

- The note of what a chat was handed, which masks its kept screen after a crash, is sealed for
  that chat alone. A note written for one chat no longer masks another chat that was given the
  same number later; that screen is not kept instead (#7129). A note purlis cannot check, such
  as one from an earlier version, is never dropped as the chat is handed more: its screen is not
  kept rather than kept with that value showing.
