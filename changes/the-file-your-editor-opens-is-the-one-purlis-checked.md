### Security

- **The file purlis hands your editor is the one it checked.** Open in your editor holds the file
  it checked and asks again right before it opens the URL or starts the program. If a folder on
  the way became a link, or another file took its place, nothing is opened and the window says
  the file changed. This covers a branch's file, a workspace file, `AGENTS.md`, a blocked save's
  file, a harness declaration and the extension record. A swap in the moment after that, before
  the editor opens the file itself, is not caught (#3185, #1044).
