### Changed

- **The main views share one look.** The explorer, a file tab's tree, the Changes view, the
  Inbox, the files view, the panel lists, Search, the vault, Dispatches, Saving, the opener and
  every empty state now draw their buttons, fields, selects, rows, trees and tables with the
  window's shared styles: one control height, one row height, a tree's levels in one step with
  straight guides, and an empty page's way out as the primary button. A filter box no longer
  carries its own glass; a pressed toggle stands on the accent (DS-12, #1844).
