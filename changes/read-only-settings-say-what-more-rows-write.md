### Changed

- **More of a read-only project's Settings stay on.** On a set-aside dispatch grant, **Give
  back** and **Remove** stay on, because they change only this machine. On Dispatch's Limits,
  the limits you set for yourself on this machine stay editable, and the project's own limits
  and overrides are off with the project's sentence as why. A harness declaration's **Open
  file** stays on: it only opens the file in your editor. Discover stays off, because it writes
  the project's committed list of repos (#1795).
