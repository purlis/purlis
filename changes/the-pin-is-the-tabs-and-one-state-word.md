### Changed

- **A pin belongs to its tab.** A tab whose only pane is empty can be pinned now, and a pinned
  tab stays pinned whatever its first pane goes on to show (#4935).

- **A chat's tab says the state its row in the Chats list says.** The tab used to name the
  board's state (*running*, *waiting on you*) while the row said *working*, *needs you*,
  *idle* or *waiting on 2 tasks*. Both now say the row's word, so a screen reader hears the
  same state for a chat wherever it is (#4935).
