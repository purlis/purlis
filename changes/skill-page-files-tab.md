### Added

- **A skill's page in the Skill studio has a Files tab**, after Text: the skill's whole folder
  (`SKILL.md`, `references/`, `evals/`, `scripts/` …) as a file tree beside the light editor's
  preview of the file you pick. A built-in or third-party skill's files are shown too, read only.
  The page's ⋯ menu gains **Open in Finder** (Files or File Explorer elsewhere), which opens the
  skill's folder (#5183).
