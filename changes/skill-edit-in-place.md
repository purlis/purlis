### Changed

- **A skill is edited in place on its page** (Skill studio preview, #3683). Edit turns the
  skill's Text tab into the editor, checked as you type ("It is a whole skill.", or what is worth
  knowing), with Save and Discard; Stop editing turns it back. While there is something to save,
  the page's header says "Unsaved changes", and what you typed stays when the studio's tab goes
  behind another. Save says "Saved. Chats started from now get this version." Leaving with
  unsaved changes (another skill, another page, back, Stop editing, or closing the studio's tab)
  asks Keep editing, Discard and leave, or Save and leave.
