### Changed

- **Grading after each edit follows a skill across a rename and a move** (#3612). Renaming a
  skill, moving it to another level or sharing it keeps grading after each edit on for it, with
  what you accepted unchanged: where a grade at its new place would run more chats, spend more,
  run other tests or compare with another version, the next edit waits for you to see the plan
  again. Deleting a skill turns it off, and a skill brought back asks for it again.
