### Added

- **No sandbox at setup says what it does, and does it in the same press.** Choosing No sandbox
  in Create a project or New project shows, in the Protection row, that a chat then runs as you,
  and which of this machine's plain-file vaults move into the system keychain. The main button
  names the move ("Open repo, and move 2 vaults to the keychain"), and that one press makes the
  project, moves the vaults (each secret written and read back first) and keeps your level. If
  a vault does not move, your level is not changed. A project whose committed `vaults.json`
  registers a plain-file vault refuses No sandbox: the row names the vault and the person who
  added it, and offers Use Basic sandbox. No sandbox is chosen only in purlis's window on this
  Mac: a link that asks for it is refused, and nothing moves.
