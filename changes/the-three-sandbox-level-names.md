### Changed

- **The sandbox levels have one set of names everywhere: Full sandbox, Basic sandbox and No
  sandbox.** The middle level was called the floor in Settings › Project › Sandbox › Your level,
  on a chat's sandbox mark and in what purlis says when a chat starts. It is now Basic sandbox
  in all of them. The settings file keeps its words (`on`, `floor`, `off`), so nothing in a
  project changes.
