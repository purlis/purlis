### Added

- **Answer once for all identical requests.** When several chats ask for exactly the same thing
  (the same host, folder or service, the same command, or the same tool and argument), Asks
  shows one row, such as "3 chats want to reach api.example.com". **Allow for all** allows each
  chat once, at the narrowest scope its own row offers. **Answer each** opens each chat's own row
  so you can answer it separately. Run grants for different commands are never grouped
  (ADR 0121 decision 6, #6009).
