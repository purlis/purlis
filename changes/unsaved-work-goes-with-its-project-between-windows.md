### Fixed

- **Unsaved skill text goes with its project to another window** (Skill studio preview, #4028).
  Moving a project to another window no longer asks about the text being edited: the window it
  moves to opens the Skill studio on it as it was. Closing a split window hands the text back to
  the main window with its projects. A quit asks about unsaved text in every window, in the
  window that holds it, rather than only in the main window.
