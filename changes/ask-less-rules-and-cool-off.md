### Added

- **Asks offers a rule after the same answer twice.** Give the same Allow to the same host,
  folder, service or reviewed program twice in a week, and its next ask offers to make it a
  rule, for this chat, this project or this machine, the narrowest that would have saved you
  the asks first. **Rules I made**, at the head of Asks, lists each rule you made, with Undo.
- **A cool-off after Don't allow twice.** When you say Don't allow twice in a row to the same
  request from one chat, that chat's same ask waits quietly for an hour, without a notification
  or a count on the ✋. Asks says so, and End cool-off brings it back.
