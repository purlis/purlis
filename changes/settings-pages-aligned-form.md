### Changed

- **Settings pages are an aligned form.** Settings has its own side column with the level switch
  and the pages, and the page beside it names the file it is kept in, with Edit as TOML. Each
  setting's help is a line under its name, every control starts at the same place, and one ⋯ menu
  at the end of each row holds Reset, Move to another file and Copy key. A value set at this level
  has a dot before its name, and a deprecated key says so (#2919).
