### Added

- **Pin a chat's browser, hand it to another chat, and see where browsers were at quit.** From a
  browser's row in the Chats list or the command palette, Pin keeps a chat's browser running
  after its chat closes; it is then listed under Pinned browsers by what its chat was called,
  and runs until you stop it, Stop all ends it, or purlis quits. A pinned browser no chat uses
  can be handed to an open chat, whose browser tools use it from their next call; one signed in
  with a login goes only to a chat that may log in with that login now. When purlis quits, the
  next start says where the project's browsers were, each address a button, and loads nothing by
  itself (#2022).
