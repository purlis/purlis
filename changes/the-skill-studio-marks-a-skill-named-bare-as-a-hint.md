### Added

- **The Skill studio marks a skill named bare as a hint.** On a skill's Overview, a skill its
  text names only in quotes beside the word "skill" carries a Hint mark, the line it is on and
  **Write skills:<name>**, which turns it into a checked reference. A skill that names this one
  bare is marked too. In an install review, a skill that comes along only by a hint says so, and
  you can untick it: the skill that names it runs without it, and the install leaves it out.
