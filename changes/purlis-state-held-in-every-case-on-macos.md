### Changed

- **Everything purlis holds in its state folder is held under every spelling of its name on
  macOS.** The rows the sandbox keeps there from a chat (the app's folder, the theme drafts, what
  skill deletes keep, the reports waiting for a chat, your approvals, every chat's settings file,
  the vaults and their key, and a state folder that is not there yet) are now held in any case on
  macOS's case-folding disk, as the Skill studio's records already were, under either spelling of
  the state folder and where `$PURLIS_HOME` puts it. On Linux, whose disks do not fold case, each
  is held as it was.
