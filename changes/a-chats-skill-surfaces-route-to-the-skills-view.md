### Changed

- **A chat's skills chip shows its skills in the Skills view.** Pressing a chat's "N skills" chip opens the sidebar Skills view on that chat. The chip is warning-coloured when the chat's set needs you. It no longer opens Use skill… (#3694).
- **Use skill… is a quick picker.** Its box takes your keys as it opens, and Enter takes the first match. A skill that takes arguments asks for them in a second step, and built-in skills are listed last. The chat's budget, routing and pins are no longer said above the list. The Skills view says them instead: under whose skills it shows, and as the chat's own cards in Needs you, each with one fix (#3694).
- **A chat's skills notices each have one action:**
  - "started without" offers Show in Skills;
  - "drafted" offers Open the draft;
  - "skills changed" adds What changed, which shows what is new, gone and changed in the Skills view (#3694).

### Added

- **The skill run chip on a chat's tab shows the tokens the run has spent so far**, where the chat's program reports usage (#2872).
