### Security

- **The app's git no longer trusts what a chat writes in a worktree's git record.** Where a chat can write `.git/worktrees/<piece>/` (sandbox level off), a link planted as `COMMIT_EDITMSG`, `logs/HEAD`, `FETCH_HEAD`, `index` or any other file git writes there made the app's git write through it into a file you own, and the app's own `purlis-brokered-commit` note could be forged the same way. Before the app commits, updates or pushes in a branch folder it now refuses a record that holds a link or anything that is not a regular file or folder, the note lives in the app's own notes folder and is written through no link, and `purlis worktree update --continue` goes on only with the rebase plan purlis kept when the rebase stopped (an `exec` line, another commit's `pick` or an `update-refs` file added since is refused). A brokered or plain commit is refused where `HEAD` names a branch other than the one the folder was cut for (#7553).
