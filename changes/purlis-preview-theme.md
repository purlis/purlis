### Added

- **Try Purlis, the new theme, as a preview.** Settings › Theme has a Purlis card marked
  Preview, beside Purlis Classic: a dark appearance from the designer's foundation, a light one
  derived from it and a high-contrast dark, set in IBM Plex Sans and JetBrains Mono with Lucide's
  icons, all bundled with purlis. Purlis Classic stays the default (#2336). The theme id
  `purlis` now names the built-in theme, so a theme folder of your own named `purlis` is behind
  it: rename that folder to keep choosing it.
