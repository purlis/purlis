### Added

- **The window's install review picks where a project skill reaches** (Skill studio preview,
  #4185). An install into the project's skills offers the grant under Lands in, the project's
  root until you pick another, as `purlis skill install --grant` does. The review then says which
  project skill the install relies on and grants to those workspaces too, and Install waits until
  that is shown.
