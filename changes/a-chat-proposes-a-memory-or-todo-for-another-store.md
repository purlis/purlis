### Changed

- **A chat's change to another persona's or workspace's memory is proposed to you, not
  refused.** A sandboxed chat that remembers something, adds a todo, forgets a memory or edits one
  in a persona or workspace that is not its own now raises a proposed change. It shows the text
  and where it would go, and for a forget or an edit the exact entry removed, or the entry before
  and after. Apply writes exactly that, and only while the memory is still what you were shown;
  Dismiss writes nothing. Moving and tidying another store, and archiving in it, are still
  refused (M74.1 T1.1-68, #6957).
