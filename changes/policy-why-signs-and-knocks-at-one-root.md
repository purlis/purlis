### Security

- **`purlis policy why` signs for, and asks the app of, the same plane.** A `$PURLIS_ROOT` that
  differs from the app's now says which plane and state folder the command signed for, instead of
  a bare refusal. The state folder `$PURLIS_HOME` names is held against rename, move and removal
  by a chat's sandbox, as the default `.purlis` and `.charter` are. A chat at sandbox level off
  runs as you and can read the key that signs `policy why`; the docs now say so.
