### Security

- **A handoff a chat starts is no more attended than that chat.** When a chat nobody is at, such
  as a dispatched task, hands work off, the new chat starts as unattended too, in whichever
  workspace it opens, and stays so: it can't publish a release, and it dispatches by the rules
  for unattended chats. A handoff you start from the window, or one an attended chat asks for,
  starts attended as before.
