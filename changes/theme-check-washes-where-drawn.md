### Fixed

- **A theme that sets only a field's error colour keeps it, over Purlis and over Purlis
  Classic.** The theme check read a field's default help on grounds no help is drawn on: on the
  danger wash, over an active tab, on a line's colour. Purlis's quiet words fall short of 4.5:1
  there, so the field's look fell and took the theme's error colour with it. A field's help is
  now read only where the window draws one, in a dialog and on a view's page, and a wash only
  over the grounds the window draws it on (#4648).
