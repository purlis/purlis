### Added

- **A project this purlis opens read-only says why in its tab.** When a project requires a
  feature this purlis lacks, or declares a format it cannot read, the window names the missing
  feature and the purlis version that has it, once, in the project's tab. Every action that
  would write a committed project file (a workspace, a persona and its icon, a vault, a todo, a
  memory's edit, move or restore, the project's and a workspace's settings, an extension's
  action, an Allow for everyone, the project's save) is turned off with that sentence as its
  reason. purlis already wrote nothing to such a project;
  now the window says so (#826).
