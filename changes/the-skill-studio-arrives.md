### Added

- **The Skill studio** (#2786). Every skill your chats get, in one place: see what each chat has and
  why any other is left out, write a skill or ask a chat to draft one, install one from a git source
  after reviewing what it adds, grade it with real chats against no skill and its previous version,
  keep a large library within each chat's skill budget, and publish or export a skill to share it.
  It is on for everyone, with no switch to turn on. [The Skill studio](docs/skill-studio.md)
  explains it from the start.

### Removed

- **Settings › You › Previews and its _Skill studio_ switch are gone**, as is the
  `PURLIS_SKILL_STUDIO` variable. The studio is always on, so a machine that had it on loses
  nothing.
