### Changed

- **Skill sources have pages of their own in the Skill studio** (behind the Skill studio
  preview). Sources leads with the updates waiting and the sources not yet confirmed on this
  machine, then your sources and the ones to start from. Each source opens on a page that marks
  its skills Installed, Update available, or with what their files do ("runs a script", "reaches
  1 host"), with Check for updates and Remove source…, which keeps the skills installed from it.
  Installing and updating are review pages with the pinned commit, every file readable under its
  own mark, and Install or Accept update fixed at the bottom. Add source… is a short dialog,
  with the branch, the folder and the sign-in under More (#3687).
