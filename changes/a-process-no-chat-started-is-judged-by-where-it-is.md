### Changed

- A merge asked by a process purlis did not start is now judged by where that process is. Outside every plane, or in a folder with a project file purlis has no sealed answers for, the shipped `strict` default decides in the hook itself: a merge it denies is refused, and one it would hold for you is left to your own terminal's prompt. Inside a plane purlis anchors, a process that is no chat's is refused, since there is no session host to ask. A chat whose sealed answers are in the deny state now starts in the full sandbox with only what its harness needs, and says why.
