### Changed

- A merge asked by a process purlis did not start is now judged by where that process is. Outside every plane, or in a folder with a project file purlis has no sealed answers for, the shipped `strict` default decides in the hook itself, and a merge it would hold for you is refused, since nobody can be asked. Inside a plane purlis anchors, a process that is no chat's is refused. A chat whose sealed answers are in the deny state now starts in the full sandbox with only what its harness needs, and says why.
