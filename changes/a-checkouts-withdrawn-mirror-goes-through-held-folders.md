### Security

- **A checkout's withdrawn agent or skill goes through the folders held on the way down too.**
  When a project stops offering an agent or skill purlis mirrored into a checkout of a
  repository kept elsewhere, the copy is withdrawn the way a workspace's generated file is: it
  is unlinked inside the folders the walk down holds, so a folder swapped for a link in the
  meantime cannot carry the removal outside the checkout (#1583).
