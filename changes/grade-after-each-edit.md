### Added

- **Grade after each edit, if you turn it on** (SK-58, #3238). It is off for every skill. A
  grade's plan offers "Grade after each edit", which says what each edit runs and may cost; once
  on, each edit you save in the Skill studio's editor grades the skill ten seconds after your last
  save, on the profile and model you picked and within the chats and dollar limit you accepted. A
  grade that would run more or cost more starts nothing and asks you again. Edits from the
  terminal or a chat never grade.
