- **A browser site can be allowed for everyone in the project.** A browser's site ask offers
  Allow for everyone in this project beside this chat and this project on this machine. The site
  is kept in the project's settings (`[sandbox] browser-sites`), for browsers alone: chats'
  commands still ask for that host. A site a teammate adds is shown to you once in a Notice, and
  reaches your browsers only after that. Each is a row of its own in Granted, and removing it
  ends the browsers it reached (#2443).
