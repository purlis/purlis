### Added

- **The Skill studio shows an org's skill controls before anything is reviewed.** On a project
  whose shared settings hold a `[skill_policy]`, Sources says once that its controls apply, with
  **See the controls**. Each source, skill and update the controls refuse is marked on its own
  row (Not on the allow list, Blocked, Too young) with the reason purlis refuses it, and an
  update too young to take says the day it can be taken; its Review button is out of reach until
  then. Settings › Skill sources shows the table read only, each key set in the team's shared
  file, and Settings › Recorded skill acts lists the installs, updates and removals this machine
  recorded.
