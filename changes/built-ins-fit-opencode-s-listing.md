### Changed

- **opencode chats list your plane's skills beside purlis's own.** purlis's built-in skills' descriptions are shorter, together at most 5,000 characters, and opencode's default skill budget is 8,000 characters, so the built-ins no longer fill it alone (spec #5714).
- **Codex chats list your plane's skills beside purlis's own.** Codex's default skill budget is 8,000 characters, the most Codex lists where it does not know its window, so purlis's built-in skills no longer fill it alone (spec #5714). Each folder of skills is named once in a Codex chat's briefing, not on every skill's line, so purlis's own leave about 3,000 characters for yours wherever purlis is installed.
