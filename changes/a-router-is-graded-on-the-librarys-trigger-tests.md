### Added

- **A skill router can be graded on your library's trigger tests** (Skill studio preview, #3233).
  Where a workspace or a persona chooses a router extension, the Skill studio's router line now
  offers Grade the router…. It shows what the grade runs and costs before anything runs, then
  runs each trigger test of the library's skills with the router in place and with the built-in
  router. The line then says how many tests pass with each, and the library's commit the grade was
  run on. The grade is recorded in the project beside the skills' grades.
