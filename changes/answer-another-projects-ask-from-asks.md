### Changed

- **Asks answers another open project's asks in place.** Under All projects, an ask from another
  project, in this window or another, is a row like this project's own: a decision shows its
  options on the row, an ask that needs typing keeps its Answer, and every project's asks stand
  in one order by their facts. The same request from chats in several projects is one row with
  Allow for all. An answer is given in the project that holds the ask, and if that ask was
  answered elsewhere meanwhile, the row says so and nothing is sent. The ✋ then opens Asks in the
  project in front and no longer switches to the project that asks.
- **The Inbox's scope switch reads narrowest first**: This workspace, This project, All
  projects, as the Chats switch does.
