### Changed

- **A Skill studio chat refused for an unapproved profile offers Approve and start in place** (Skill studio preview, #3942). Try it, Ask a chat to draft a skill and a draft's redo start their chats without the new-chat picker, and purlis refuses a profile nobody has approved on this machine. That refusal now has an Approve and start… button. It asks the picker's own question, showing the command the profile would run, and once you approve it starts the same chat with its request typed and not sent. Before, you had to leave the studio and approve the profile from a new tab.
