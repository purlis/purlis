### Added

- **Sign in with GitHub, in your browser.** The welcome's sign-in page and Settings › You ›
  Accounts have **Sign in with GitHub** beside the token: purlis shows a short code, you confirm
  it on GitHub's own page, and you come back signed in on github.com without ever handling a
  token. The sign-in is kept in your system keychain, renewed by purlis before it expires, and
  never reaches a chat. If GitHub ends it, a notice names the account and offers **Sign in
  again**. A GitHub Enterprise server still signs in with a token (#729).
