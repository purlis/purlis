### Fixed

- **A chat row's card no longer blanks an open artifact.** Resting on a chat in the sidebar
  while an artifact's tab was open put the whole page away until the card went. The card now
  stands under its row, inside the sidebar, and the page stays shown. A dialog, or a menu
  opened from the artifact's own bar, still puts the page away while it is up, and a dialog
  now does so wherever it stands, so the page can't be used behind it (#6226).
