### Changed

- **New skill… asks how you want to make the skill** (Skill studio preview, #3684). Write it
  yourself, ask a chat to draft it, or install one from a source. Writing it yourself asks for a
  name (checked as you type: its shape, a built-in skill's name, one the level already has), what
  it does, where it lands and a template, then opens the new skill's page with its text in the
  editor. Asking a chat asks what the skill should do and where it lands, and opens a chat with
  the request typed and not sent; its draft comes back to Drafts. The Skills view's New skill…
  opens the same dialog. The inline New skill panel and the empty studio's three starts are gone.
