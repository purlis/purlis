### Added

- **A right-click in a terminal has Copy, Paste and Select all.** A chat's or a shell's terminal now
  opens a menu of its own: *Copy*, which is off until something is selected and puts on the
  clipboard exactly what the keyboard's copy does, *Paste*, and *Select all*, with a Mac's keys
  said beside them. The rows a right-click on a pane had before (a new tab, the splits, ending
  the chat) follow under a line. *Paste* types the clipboard's text as the keyboard's paste
  does, bracketed when the program asked for that, so several lines cannot run one by one. It
  pastes text only, up to 1 MiB; when it pastes nothing the pane says why. On a Mac a right-click on a word
  selects it first. A full-screen program that turned mouse reporting on
  still gets a plain right-click; **Shift+right-click always opens the menu**. The menu key
  opens it under the cursor, and so does Shift+F10 while no program has the mouse; a second
  Shift+F10 closes the menu and sends the key to the program.
