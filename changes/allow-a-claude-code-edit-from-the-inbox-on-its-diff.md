### Added

- **See what a Claude Code edit writes before you allow it from the Inbox.** A Write, Edit or
  MultiEdit permission ask now shows its change in the same side-by-side view the file comparison
  uses: the whole new file for a Write, and for an edit the text it replaces beside what it puts
  there. Allow is offered for this one edit once the change is drawn, and Deny stays. An edit the
  Inbox cannot show whole (too long, not text, holding characters it cannot draw as they are or
  what looks like a credential, or an input it cannot read) says why and offers no Allow; you
  answer it in the chat (#1146).
