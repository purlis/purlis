### Fixed

- **A menu's rows no longer overlap.** In a menu taller than its room, such as a chat tab's
  menu in a project with many personas, every row was squeezed to one line and drawn over the
  description of the row above it. Each row is now as tall as its title and description, and the
  menu stays inside the window and scrolls. Menu rows are written one step smaller, and a
  description shown in a row is no longer repeated in a tooltip.
