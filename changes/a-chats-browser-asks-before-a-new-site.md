### Added

- **A chat's browser asks before it goes to a site new to the project.** A link a page offers
  loads, so public sites are readable; an address the agent writes for a new site, a form it
  submits there, or its typing on a page or frame of one, asks you first. A chat's sites wait as
  one ask, with Allow for this chat, Always allow in this project on this machine, and Keep
  blocked. An Allow is a **browser site**, for the browser alone: the chat's own commands still
  ask for that host. Browser sites are listed apart in the Granted list, and removing one ends
  the browsers it reached. On the open web nothing asks (#2018).
