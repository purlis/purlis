### Changed

- **More tools' folders join the names a chat doesn't write, and you can allow one for one chat.**
  `~/.claude/rules` and the folders fish, Neovim, bash completion and the session bus load code from
  under `~/.local/share` are now held. At the default sandbox level, a block on one of these, or on
  the `gh`, `glab` or `kubectl` settings, offers **Allow for this chat**, naming the folder whole.
