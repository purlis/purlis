### Added

- **A chat's browser marks what a scrolling box or frame does not show.** A snapshot or a find
  marks an element `(out of view)` when a box it is in that scrolls (a list, a chat log, a side
  panel) or the frame it is in lays it out beyond what it shows, even while that box or frame is
  in view, so the agent scrolls over the box to reach it (#2564).
