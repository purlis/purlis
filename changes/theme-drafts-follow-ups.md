### Changed

- **Keep says when the theme folder it replaces changed since the draft started.** A theme
  draft records the folder it copied, and Keep's question says so before it replaces a folder
  that your own edit, a pull or another chat changed since. Closing a chat that kept several
  drafts asks who draws each one. A refused kept theme's Notice waits while a draft is drawn,
  and the strip says so. **Use in the whole project** says the project's next save commits the
  theme for everyone. The drafts of a chat that is no longer open are deleted (#2708).
