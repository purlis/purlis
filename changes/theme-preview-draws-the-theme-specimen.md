### Added

- **A chat can see a theme without seeing your window.** purlis draws the theme specimen, a
  fixed page of sample content (every control, a chat pane, an editor, a terminal in every ANSI
  colour, a Settings page, a dialog and a Notice), in a hidden window of its own, and a chat's
  new `theme_preview` tool returns its picture in any theme and appearance, alone or two side
  by side (#2330). The picture is taken on Linux; on macOS and Windows the tool says it takes
  none there yet.
