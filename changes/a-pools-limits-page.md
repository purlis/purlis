### Added

- **A pool's limits have a page.** Under each pool in Settings › You › This machine › Pools, Limits
  lists them by what they affect, each with its unit, its default, a mark on a value you set, and
  Reset. Values are checked as you type (#4285).
- **A moved chat over a pool's limit offers to raise it**, as Start a chat does: saving the value asks
  for the move again (#4313).
