### Changed

- **The Chats view says when, and how many** (#3484). Each chat's row ends with the time it came
  into its state: "now", "2m", or the clock time, such as "10:42". In a narrow sidebar the name
  is cut short first and the time stays whole. The Needs you and Working chips show how many
  chats each would leave, and a screen reader hears the count once, after the chip's name.
  Where the list is grouped by workspace, each workspace's name has the same group heading as
  the other sidebar views, with its count at the end.
