### Changed

- **A command over several lines is shown on them in the Inbox.** A permission whose command
  runs over several lines draws each line on its own line in its row, up to five, and counts
  the rest ("and 12 more lines"). The row says why only Deny is offered: "Allow is not offered.
  It runs over 3 lines." The lines are the row's own line split where the command breaks one,
  masked and cut as that line is, so they show nothing it does not. Where they could not be
  shown that way, the line stays as it was and the row says how many lines the command runs
  over (#3502).
