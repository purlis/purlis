### Added

- **Create a project and New project each ask for your protection, in one row.** Pick Basic
  sandbox (recommended), Full sandbox or No sandbox, each with a line of help; Basic sandbox is
  already chosen, and the page's own button still finishes setup in one press, for a project on
  this Mac or on GitHub or GitLab. For a new project, your choice is kept as your own level on
  this machine, in `purlis.local.toml`, never in a committed file, and it is the same value
  Settings › Project › Sandbox › Your level shows and changes. A repo opened into a project you
  already have keeps that project's level, which the page shows; change it in Settings. Where a
  policy requires the full sandbox, the levels below it are out of reach, with the policy's
  reason.
