### Added

- **A persona's tool that is a general-purpose program says so on its Allow.** curl, wget,
  httpie, base64, tee and the like fetch, send, copy, encode or write content as the chat's
  arguments say, so such a program can show the values it receives in the chat's output. It
  stays allowed as a tool; the Notice, Settings › Sandbox and the Granted list now add one
  sentence beside it, so you allow it only for a persona you trust with those values. The list is
  not exhaustive, and a tool without the sentence is not thereby a safe one: any program can show
  what it is handed if its arguments ask it to. Every Allow you made before stands (T-4).
