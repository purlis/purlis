### Added

- **A persona's tool that is a general-purpose program says so on its Allow.** curl, wget,
  httpie and the like fetch, send or write content as the chat's arguments say, so such a
  program can show the values it receives in the chat's output. It stays allowed as a tool; the
  Notice, Settings › Sandbox and the Granted list now add one sentence beside it, so you allow it
  only for a persona you trust with those values. A narrow tool's Allow is unchanged, and every
  Allow you made before stands (T-4).
