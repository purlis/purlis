### Added

- **Pool setup: join your team's pool on a cluster.** A teammate whose sign-in can't read the
  cluster's install now passes Check the cluster and Install as "Installed by your team", with no
  install buttons, operator image, uninstall or minting commands shown. Where they can't list the
  pools they type the pool's name their admin gave them. Before anything is pinned they paste the
  cluster operator key their admin gave them, and purlis pins it only if it is the key the pool
  names. A pool's finished Pool step shows the key pinned there, for the admin to give teammates.
- **A changed cluster operator key asks again in Pool setup.** When a cluster pool's Pool names a
  key the pinned one never vouched for, its Pool step shows both keys and pins the new one only
  once you paste the key your admin gave you. Your runner stays the one paired.
