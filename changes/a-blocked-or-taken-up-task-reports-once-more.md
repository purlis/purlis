### Fixed

- **A blocked task can report what it found next.** A task whose report came out blocked, or
  one you took up again after its report by typing in its tab, can now send one more report.
  It reaches the chat that asked and wakes it like any report, and the Activity tab shows both
  reports. Before, purlis refused every report after a task's first, so you had to carry the
  result across by hand (#1768).
