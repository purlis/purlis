### Added

- **A theme can restyle the Needs-you count on the activity bars.** The new `needs-you.count` and
  `needs-you.count-text` colours draw it, and default to the needs-you colours, so no theme changes
  until it sets them. The theme check holds the words to 4.5:1 on the fill, the fill to 3:1 on each
  bar ground, and the fill apart from a plain count (#3098).
