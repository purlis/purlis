### Fixed

- **What you type into a browser is kept out of the agent's answers as you typed it, not word by
  word on the way.** While you drive a chat's browser, purlis keeps each field's latest value,
  each run of keys you typed and what you pasted out of every answer the agent gets. A short word
  you passed through on the way to a longer value is no longer blanked on every page. The site
  where you typed, whose pictures and canvases a screenshot paints over, is the site of the page
  you typed on as it shows, even while it is loading another (#2311).
