### Added

- **Add a service on this Mac by its port in Settings.** Settings › Sandbox › Network has *A
  service on this Mac*: type one port and allow it for every chat of this project on this
  machine, or for one open chat only. It is judged, audited and kept exactly as an Allow on the
  Notice a refusal raises, so the same values are refused (a range, every port, a port purlis
  itself listens on, a scope past those two, a policy lock), and it shows in the Allowed list
  with Remove (#1970).
