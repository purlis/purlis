### Added

- **The window shows the project's policy.** A chat's pane head says the template its project
  runs (`watch`, `team`, …) and how many families it sets apart, with the whole policy on the
  mark's tooltip. **Settings › Project › Policy** lists the template, each family set apart and
  how your chats run it, what an administrator locks, and a loosening that waits for your
  Accept. It also counts what the families set to `log` let through ("Would have blocked: N"),
  which opens the enforcement log: each line's rule, family, chat and host, never a command, a
  path or a value (rulings Q308a and Q308b; `docs/policy.md`).
- **The move to `watch` is announced once.** The first project you open that names no policy
  says that blocks are now off by default, and how to turn a family back on under `[policy]`.
