### Changed

- **Changes is in the Panel's left half, after Repos**, and the left sidebar keeps Chats,
  Explorer and Search. ⌃⇧G and _Show the Changes view_ open it there, bringing the half back if
  it was away. Every view's key opens the view wherever it lives (spec #1736, #1739).

### Added

- **The Lower icons carry badges**, as the sidebars' icons do, so they show while their half is
  away: Changes counts uncommitted files, and Repos shows how many commits the clones are behind
  and ahead, only while one is behind (#1739).
