# Shell and UI features: leading dev tools vs purlis (2026-10-20)

**Question.** Which shell and UI features do VS Code, Zed, JetBrains IDEs (2025+), Cursor, Warp, Linear and Raycast have that purlis/purlis lacks?

**Method.**
- Competitor facts come from official docs and changelogs only. Every URL was fetched on 2026-10-20 and returned HTTP 200.
- purlis facts come from `purlis/purlis@main`, read at `app/src` and `docs/`.
  - In the sandbox, `git clone` could not write into `.git`, so the source came from the GitHub tarball (`gh api .../tarball`).
  - The tarball stream broke partway through `crates/`. `app/` arrived whole. `docs/design-system.md` and `docs/ui-primitives.md` were fetched one by one through the contents API.
- File references below are relative to the repo root.
- **Not found** means a grep of `app/src` turned up nothing. It is not proof the feature is absent.

**Classes.**
- **(a)** UI-system work. It belongs in a shared-component and theming program (primitives, tokens, the palette, layout, keys).
- **(b)** A product feature for a separate backlog.

## What purlis already does well (parity or better)

These are not gaps. They are listed so nobody re-files them.

- **Palette.** A keyboard-first palette (`⌘K`/`F2`/`Ctrl-K`) is the primary input. Rows that can't run stay listed, with their reason (`app/src/Palette.tsx`, `app/src/actions.ts`).
- **Settings.**
  - Three scopes: You, Project and Workspace (`app/src/settings/groups.ts`, `app/src/settings/links.ts`).
  - A filter within each level (`narrowed()` in `app/src/settings/SettingsTab.tsx`).
  - Deep links that focus the exact field (NO-7, `app/src/settings/links.ts`).
  - A modified mark and Reset on each setting (`app/src/settings/components.tsx`).
  - Settings groups listed as palette rows (`settingsGroupRows` in `app/src/actions.ts`).
- **Size and density.**
  - Two text sizes, one for the window and one for the terminal, on `⌘=`/`⌘-`/`⌘0` (`app/src/textSize.ts`).
  - A comfortable/compact density (`app/src/appearance.ts`, `Density` in `app/src/theme/theme.ts`).
- **Reduced motion.** It is centralised: every duration is a token and drops to 0ms under `prefers-reduced-motion` (`app/src/theme/motion.ts`). There is also a forced-colors sheet (`app/src/theme/forced-colors.css`).
- **Splits.** Right and down (`pane.split.right`, `pane.split.down` in `app/src/actions.ts`; `app/src/LayoutPanes.tsx`). A pane can move to its own tab or a new window (`app/src/menuWords.ts`).
- **Inbox.** Asks are grouped by chat chain and ordered by age (`app/src/inboxRules.ts`). There is Mark all read and Dismiss all (`app/src/Inbox.tsx`), plus quiet hours for system notifications (`app/src/notificationPrefs.ts`).
- **Empty states.** One shared component used by every panel list and view tab (`app/src/EmptyState.tsx`). Guided first-run steps are modelled as a state machine (`app/src/guidedSteps.ts`, `app/src/Onboarding.tsx`).
- **Themes.** Light and dark appearances (`app/src/theme/theme.ts`), a theme gallery (`app/src/settings/themeGallery.tsx`) and theme drafts (`app/src/themeDrafts.ts`).

## Top 10 picks, ranked by daily impact

1. **#1 Fuzzy palette matching with recents and frecency (a).** The palette is purlis's primary input and gets hit dozens of times a day. Typos and "what I ran last" are the most common friction.
2. **#4 Central key registry (a).** It is the foundation for #3, #5, #6 and #17. Today's per-module key claims are the reason none of those exist.
3. **#17 MRU tab switcher (Ctrl+Tab) (a).** Moving between agent chats is the core loop. Every competitor has this.
4. **#11 Inbox snooze and priority (b).** Needs-you is purlis's differentiator. Linear's snooze/priority/unread-first is the proven pattern for a queue of asks.
5. **#3 Shortcut on each palette row (a).** This is how people learn the keys, and it costs little once #4 exists.
6. **#7 One settings search across all scopes, settings as palette rows, `@modified` filter (a).** It reuses the deep links and `modified` tracking that already exist.
7. **#10 Split ergonomics: maximize a pane, directional focus, drag to an edge (a).** It suits watching agents side by side.
8. **#20 Shared Form/Field primitive (a).** 39 hand-built dialogs mean uneven validation and focus. It also unblocks extension forms in #24.
9. **#8 Moving views across sides from the UI (a).** Today this needs a hand edit of `layout.json`, which nobody discovers.
10. **#6 Generated shortcut cheat sheet (a).** It falls out of #4 almost for free and helps onboarding.

Just outside the list:
- #12, per-source notification settings (b).
- #22, per-component theme tokens for the status line, inbox and palette (a).
- #5, the full rebinding editor (b), which comes after #4.

- JetBrains publishes no theme key count.
