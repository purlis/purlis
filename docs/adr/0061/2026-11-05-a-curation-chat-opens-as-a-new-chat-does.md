# Amended (2026-11-05): a curation chat opens as a new chat does (#5289)

Records the person's acceptance of [the moving panes spec](https://github.com/purlis/purlis/issues/5288);
[ADR 0113](../0113-panes-make-room-while-a-drag-holds-a-preview-not-a-change.md) says what it amends.
It replaces the amendment of 2026-11-02's "takes the focused pane".

A curation action is a chat the person starts with a press, so it opens as a new chat does: it fills
an empty pane of the front tab, or else gets a new tab, and replaces nothing. The rest of that
amendment stands: its name, where it is filed, and the Curate ▸ rows.
