# Amended 2026-10-28: a grade's consent covers the profile, model and limits its plan shows

Ticket #3622. It adds to §3 ("What runs is what the plan showed") and §4.

**The consent a press hands back is one digest of what the plan grades and of the terms it shows**:
the profile and the model its chats run on, the token cap and the dollar limit
(`skills::grades::consent_on`). A grade starts only where the plan it would start on now has the
same digest, so it runs on the profile, model and limits the person read; otherwise the press is
refused with a sentence, and the window shows the new plan to read and press again.

**Turning on "Grade after each edit" (#3238) checks the same digest**, and what it keeps as
accepted names the model the chats ran on beside the profile, so a saved edit grades only on the
profile, model and limits the plan showed; any other waits for the person to see the plan again.
