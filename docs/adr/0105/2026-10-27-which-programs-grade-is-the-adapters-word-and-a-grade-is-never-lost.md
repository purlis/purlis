# Amended 2026-10-27: which programs grade is the adapter's word, and a grade is never lost

Tickets #3310, #3352 and #3353, the follow-ups of SK-16's reviews (#3229). They keep §3, §4 and §5
as they were decided and say where each one is held.

**Which programs can grade is a capability each harness adapter declares** (§3, #3310). "A Claude
Code profile alone" stays the operator's ruling, as only there can purlis hold a grade's chat to
purlis's MCP server and read what it spent. The neutral core no longer names the program: each
adapter says `can_grade`, with no default, and a grade's chat on one that says no is refused with a
sentence that names the programs that can. Claude Code says yes; Codex and opencode say no until
#3272. What keeps one program's chat from ever asking (its settings and its flags) is that
adapter's to read (`grade_refused`), so the core asks it and names no file and no flag.

**A grade's chat starts in a mode that asks, or not at all** (§3, #3352). A grade's session settings
pin Claude Code's `default` permission mode, but a `--permission-mode` in the profile's command
outranks them, so a mode that asks nobody would keep a grade's "end at the first ask" from ever
firing. A profile whose command names any mode but `default` or `plan`, in any spelling the bypass
check reads, or names the flag with no mode after it, is refused with the bypass flags' sentence.

**A grade is never lost and never stays running** (§5, #3353):

- **Rows read back are checked whole.** A row whose spend or report does not hold together (a cost
  below nothing, a test triggered more often than it ran, a share out of bounds, a reason with a
  control character, among the rest `docs/plane-format.md` lists) is skipped, as a row that says
  more than purlis writes already was.
- **A grade is held under way while it runs**, in this machine's state, as the row it would be were
  it interrupted then. Its end takes it away. At the project's next start, a grade still held there
  that no running purlis holds is recorded as `interrupted` (a sixth way a grade ends: no chat
  scored), so a crash, a fault or a quit never loses it. The chat it ran then is ended with every
  chat nothing reattached (#2006).
- **A panic inside a grade** takes it out of the running grades, records it as interrupted, and
  tells the window it failed. A release build aborts on a panic, so there the next start's record
  is what holds.
- **The Grades panel is of one copy**: same-named copies at two levels are two skills, so the panel
  reads the rows of the copy the skill's tab shows, never every level's.
