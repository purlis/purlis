# A grade read from a source is the publisher's claim, never purlis's own

**Amends [ADR 0105](../0105-a-grade-is-real-chats-purlis-runs-cost-first-scored-by-skill-runs-and-recorded-against-the-skills-version.md), 2026-11-08**, ticket #4346, by the operator's ruling of the same day. [ADR 0100's amendment of the same day](../0100/2026-11-08-a-source-carries-a-skills-grade-beside-its-folder.md) lets a source carry a skill's grades in a file beside its folder.

- **A grade is what purlis measured, and only that.** §5's eval record holds the grades purlis's own chats ran. A grade read from a source is a sentence someone committed. purlis ran none of its chats and can't check any of its numbers, so it never goes into the record, the skill's Grades tab, its history, or the comparison a new grade is drawn against.
- **The install and update review shows it as the publisher's**: whose it is, that purlis has not checked it, and whether it was measured on the version under review. ADR 0100's amendment has the words.
- **Installing does not carry it into the plane.** The installed copy has no grade until a person grades it here, and then the grade is purlis's, under §5.
- **What a grade sends out is unchanged.** Publish writes the rows the request's description already held, plus each grade's tree, and nothing §5's record holds beyond them.
