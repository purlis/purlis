# Amended 2026-11-01: a run that hangs up once the person is asked costs the pace

Adds to the amendment of the same day on a refused mint's pace, whose item 3 keeps its words: a
refused run still reaches the desktop's gate and Ask.

A run the cluster refused that hangs up after it went to the desktop counts on the same pace as one
the window refused, since the person may have seen an Ask raised and withdrawn; the runner can't
tell whether the Ask was up yet, and the cost falls only on that chat's tool. The next runs are
refused on the runner until the pace has passed. A run that hangs up before it goes to the desktop
costs nothing, and a person's yes clears the pace as before.
