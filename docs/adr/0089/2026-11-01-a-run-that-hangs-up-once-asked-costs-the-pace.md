# Amended 2026-11-01: a run that hangs up once the person is asked costs the pace

Adds to the amendment of the same day on a refused mint's pace, whose item 3 keeps its words: a
refused run still reaches the desktop's gate and Ask.

A run the cluster refused that hangs up after its Ask was raised counts on the same pace as one the
window refused, since the person saw an Ask raised and withdrawn. The next runs are refused on the
runner until the pace has passed. A run that hangs up before its Ask is raised costs nothing, and a
person's yes clears the pace as before.
