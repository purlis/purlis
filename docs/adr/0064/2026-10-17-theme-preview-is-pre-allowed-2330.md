# Amended 2026-10-17: `theme_preview` is pre-allowed (#2330)

Ruled by the operator on 2026-10-17. The chat tool `mcp__purlis__theme_preview` joins
`chattools::PRE_ALLOWED`. It is an `allow` only, by its full name, for Claude Code only, and an
`ask` or `deny` the operator sets still wins.

- **It returns only pictures of the theme specimen.** The specimen is a fixed page of sample
  content that the app draws in a hidden window of its own, a window granted no command. The
  page is handed the built-in themes and the one theme asked for, and nothing of the person's.
- **It names a theme and an appearance, and nothing else.** It takes no workspace, path or
  command, and it writes, starts and sends nothing.
