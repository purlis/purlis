# Amended for #2144, a code across several boxes, 2026-10-18

Spec #2008 rules that what the person typed never reaches the model (the operator's ruling of
2026-10-14). The amendment for #2014, item 4, keeps what a blanked element holds out of every later
answer; the amendment for #2311 says which reads are kept. This note adds what a group of blanked
boxes holds together. Nothing else changes, and the session protocol does not.

1. **Boxes next to each other hold one value.** Blanked elements of one frame that are next to each
   other on the page, with nothing between them but separators (text of fewer than 3 characters),
   are a group, such as a code typed one character a box. What the group's boxes hold, joined in
   their order on the page, is kept out of every later answer as one more value, with the
   separators and without them. It is kept wherever what the boxes hold is kept: on that page for
   an element a login blanked, and on every page of the browser for what the person typed, with
   the key just typed in its box. *D-2144-1.*
2. **A group keeps its latest value.** A later read of a group is read as a field's is (the
   amendment for #2311, item 1): it drops the group's earlier joined values that it contains while
   they are shorter than 8 characters, and nothing of any one box. A code typed box by box is kept
   out as the code, not as each part of it on the way. *D-2144-2.*
