# Amended again for #2144, separators of a code, 2026-11-09

The amendment for #2144 keeps what a group of blanked boxes holds together out of every later
answer, found with any spaces or dashes between its characters (its item 1). This note widens
which separators count; a group's reads stay as that amendment has them, and nothing else
changes.

1. **Dots, slashes, middle dots and bullets count where one sits between every pair.** What a
   group holds is found with spaces and dashes anywhere between its characters, as before, and
   with a dot, slash, middle dot or bullet only where that same character is the separator
   between every pair of the code's characters in the match, and no letter or digit runs on from
   either end of it. So `7.3.9` is found as the code `739`, and a price such as `$7.39` or a date
   such as `7/3/91` is not. *D-2144-4, decided in implementation, to be confirmed.*
