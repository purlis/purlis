# Amended 2026-10-31 for #3241: a terminal asks the window for a grade

§5's table gains two powers (session protocol 1.63), on the operator's ruling of 2026-10-31.

**`ask_grade` is `terminal`'s alone.** It spends the person's account on their own yes. Its
credential is one a chat's sandbox denies, and a peer inside a chat is refused every scope on this
socket, so no chat reaches it. The window has its own Grade button and is not granted it.

**`answer_grade` and `grade_step`, and hearing `grade_asked` and `stop_grade`, are `local-ui`'s
alone.** The host asks one window, the first linked that holds the project at that path, and takes
an answer or a step only from that link. A step is pushed to the asking link alone.

**No link between hosts carries any of it.** `remote-link` holds neither power and a relaying host
refuses the commands, so a terminal on one machine never spends through another.

What the grade itself consents to, and how it stops, is ADR 0105's amendment of the same date.
