# Amended (2026-11-02, plane#2010's ruling): a person may lift one held folder for one chat

Ruled by the person, 2026-11-01 and 2026-11-02. This amends "Amended (2026-10-06): a block is never
a dead end", item 2, which keeps what later code loads out of every grant. A short list of later-code
names (`MAY_LIFT`) gets an Allow at the floor, because their owners write them in ordinary use:
`gh`, `glab` and `kubectl` settings, and what fish, Neovim, bash's completion and the session bus
load under `~/.local/share`.

- **One folder, named whole.** The Allow names that name below the home, and nothing else: not a
  copy elsewhere, and not a path reached through a link. Each start judges it again.
- **This chat alone.** It is a Write grant at the chat's level, never kept for every chat, never
  offered as Always, and goes through the same audit.
- **At the floor alone.** The full sandbox keeps today's refusal, and a compile there ignores it.
- **Never** git's config, ssh's, a shell's own startup files (`.zshrc`, `.bashrc` and the like, and
  fish's `config.fish` folder), what the system starts at login, or a harness's or an editor's own
  settings. The `MAY_LIFT` folders that fish and Neovim load are the only shell and editor folders
  on the list. `.claude/rules` is held with no Allow.
- **Their parents are made.** Before a Claude Code chat starts at the floor, purlis makes any
  missing folder above a `MAY_LIFT` name in the home, empty: Claude Code pins every folder above a
  held path, so a tool's first run could not make them, and a lift could not be used.
- **What it costs.** A chat with this Allow can leave code a later program runs outside any sandbox.
  The Notice says so.
- **How far it goes, by sandbox.** Under a Seatbelt profile it lifts that one path, and every other
  copy of the name stays held. Claude Code's own sandbox can't write one path past a `denyWrite`
  glob, so there the Allow drops that name's glob: that one chat may write that name at any depth for
  its run, and the Notice says so. This case alone amends "one folder": the person ruled it
  acceptable for a grant held by one chat and never offered as Always. A chat purlis wraps on Linux
  wasn't built, and keeps today's refusal.
