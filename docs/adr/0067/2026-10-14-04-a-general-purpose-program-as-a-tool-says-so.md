# Amended (2026-10-14, the operator's ruling T-4): a general-purpose program as a tool says so on its Allow

Ruled by the operator ("agree with suggestion"). This extends the T-1 amendment above and the
paragraphs of section 1 on a persona's tools.

- **A general-purpose program stays a tool.** A program that fetches, sends, copies, encodes or
  writes content as its arguments say (curl, wget, httpie, base64, tee and the like) can show the values it receives in the
  chat's output, since the chat writes its arguments. purlis refuses no tool by its kind.
- **Its Allow says so, in one plain sentence**: "curl can show the values it is handed in the
  chat's output; allow it only for a persona you trust with them." The Notice, Settings ›
  Sandbox and the Granted row say it beside the tool's line, for each such tool.
- **Which programs**: a short list of program names in `sandbox::tools`, reviewed with each
  addition, matched without regard to case on the tool's name and on the file name of each
  program that name finds on the app's search path, as found and as its links resolve. The list
  is not exhaustive: a tool without the sentence is not thereby a safe one, since any program can
  show what it is handed if its arguments ask it to.
- **The sentence is said, never allowed.** It is carried beside the line (`cautions` on the
  persona's hosts and on the Granted row), not in it: the tool's line and the digest an Allow is
  bound to are unchanged, so every Allow made before this stands.
- `crates/purlis-core/docs/secrets.md` and the plane-format `tools` row state the limit.
