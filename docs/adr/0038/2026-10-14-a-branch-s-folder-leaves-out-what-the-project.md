# Amendment, 2026-10-14: a branch's folder leaves out what the project keeps (qw374) — to be confirmed

**To be confirmed by the operator.** The amendment above reads the plane root against the list
of what purlis keeps to itself. A workspace's clone and its branch folders are inside the
project too, so the same list is read for them (`files/kept.rs`, ADR 0067 as amended the same
day):

- **A branch's tree, a file's open, a path placed or named, a folder watched and the editor
  hand-off leave out what the list names**, by spelling and by what the file is, as at the plane
  root. A vault's file registered inside a clone is neither listed nor opened on that
  workspace's tab, and another name of a kept file opens no more than its first.
- **Search, the file palette, a comparison and the change marks leave them out too.** A kept
  file is not searched, not found by name, not among a comparison's files at either end of a
  move, not compared, and not marked as changed.
- **Where the list cannot be told whole, a branch's files are not read either, in a project
  that runs its chats sandboxed**, with the sentence that names Doctor. The list is what a chat
  is kept from: where the project runs no chat sandboxed there is no such list in force, and a
  branch reads as it always did. A project whose own file is gone or does not read is not known
  to run none, and is read as one that does.
- **The plane root keeps its own rule**, whatever the sandbox is: nothing of it is listed by a
  list that is not whole. One file of it still opens, the half of the vault registry to put
  right, so what is wrong with it can be read in the window; the vault's view lists the vaults
  it can and says of each other entry what is wrong with it.
- **A `plain-file` vault with no file said on this machine yet keeps the list whole** (ADR
  0067): the plane root lists, and the vault's view says the vault is not set up on this
  machine.
- **The rule for clones stays the plane root's alone.** Inside a branch's folder a nested
  repository is drawn as it always was.
- **The offered list fails closed by itself**: where the list is not whole it holds at most the
  registry to put right, and where the project's workspaces cannot be listed nothing under
  `workspaces/` is on it, whoever asks.
- **A link's folder watch goes on to the app only when every folder names a branch.** A call
  that does not say its folders as a list is refused as one that names the plane root is.
