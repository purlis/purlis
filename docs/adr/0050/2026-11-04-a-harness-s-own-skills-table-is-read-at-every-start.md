# A harness's own skills table is read at every chat's start

**Amends [ADR 0050](../0050-a-harness-plugin-is-chosen-per-project-through-one-adapter-per-harness.md), 2026-11-04**, ticket #2786 (SK-23). [The 2026-10-21 amendment](2026-10-21-codex-turns-a-plugin-off-per-chat-and-every-harness-a-skill.md) said a chat's start reads `[harness_skills]` only while the Skill studio's flag is on. The flag is gone ([ADR 0099 as amended 2026-11-04](../0099/2026-11-04-the-skill-studio-flag-is-gone.md)), so the table is read wherever the project's skills reach the chat, which is every chat of this build. The one exception is a runner's chat whose older desktop said no, in a project that does not require `project-skills` (`harness_plugin::for_start`). Nothing else in that amendment changes.
