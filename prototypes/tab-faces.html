Questions for you

My recommendation comes first in each.

Remove the tasks count from the tab?Yes. It eats a third of a narrow tab. It repeats the tree in the list, and the mark already says "waiting on tasks". The menu it opens is useful, so that moves to the head's state button, and ⌘⇧J still opens it. The cost: seeing how many tasks a background tab has now takes a hover.
How wide should a tab be at its smallest?160 px, which fits about 15 characters. Tabs past that go behind "N more ▾", which already exists and is sorted by activity. So you see fewer tabs at once, but you can read them. Try 140 and 180 above.
Show that a tab is split?Yes, as a small picture of the layout's shape in place of "+1". It's quieter, it tells you the shape, and it stays readable at any width. And a split tab's mark shows its most urgent pane, so a pane that needs you can't hide behind the focused one.
Does a split rename the tab?No: it keeps its first chat's name, the pane at top left, and doesn't change as you move between panes. So you find a tab where you left it. The heads already say what each pane is. If that chat leaves, the tab takes the next one's name. This changes today's rule, where a tab's name follows the focused pane.
Renaming in a one-chat tabA tab that shows one chat has no name of its own: it shows the chat's. So Rename there renames the chat, and says so. A tick for "Only this tab" keeps the chat's name, for the rare case you want both. This is simpler than a suggestion you'd have to answer each time.
Renaming in a split tabRenames the tab only, and says the chats keep their names. Each pane's ⋯ renames its chat. A tab's own name can be cleared, so it goes back to its first chat's name.
Where Rename chat appears⋯ on a pane, the list row's menu and the palette, with F2 as today. It's missing from the pane's ⋯ now, as you found.
A task's failure on the tabThe mark shows it until you've seen that chat, then returns to the chat's own state. So a background tab can still tell you something went wrong, without a count chip.
